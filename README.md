## 🧠 What is this?

ShortMan Dictionary is a web-based slang dictionary built for people who are **terminally online** and proud of it.

Every entry includes:
- 📖 **Formal definition** (for when your parents ask)
- 🌐 **Internet meaning** (what it actually means)
- 🧠 **Brainrot meaning** (maximum chaos mode)
- 🗣️ **Pronunciation guide** (with personality)
- 💬 **Usage examples** (from the trenches)
- 📍 **Where you'll see it** (TikTok, Reddit, Discord, etc.)
- ✨ **Vibe rating** (emoji-based energy assessment)

<br/>

## ✨ Features

| Feature | What it does |
|---------|-------------|
| 🧠 **Brainrot Mode™** | Toggle to replace all definitions with their maximum-chaos equivalents |
| 🔍 **Instant Search** | Find any slang word instantly with fuzzy matching |
| 🔤 **A-Z Navigation** | Browse alphabetically like a real dictionary (but cooler) |
| 🏷️ **Category Filters** | Gaming / TikTok / Reddit / Meme — find your niche |
| ❤️ **Favorites** | Save words for quick access (we won't judge) |
| 🎲 **Random Entry** | Discover words you didn't know you needed |
| 👥 **Community Words** | Submit your own slang, upvote others |
| 📤 **Share Cards** | Generate shareable meme cards for any entry |
| 🌙 **Dark Mode** | For 3am slang browsing sessions |
| 📱 **Fully Responsive** | Works everywhere you doom-scroll |

## 🚀 Quick Start

```bash
git clone https://github.com/MahanKenway/ShortManDictionary.git
cd ShortManDictionary
npm install
npm run dev
```

Open `http://localhost:5173` — search "rizz" — get enlightened.

## 🤝 Contributing

**Got a slang word that's missing? Pull request it.**

1. Fork the repo
2. Add your word to `src/data/slangData.js`
3. Include: `word`, `meaning`, `internetMeaning`, `brainrotMeaning`, `examples`, `category`, `vibeRating`
4. Open a PR — we review faster than you can say "no cap"

If TikTok uses it, it belongs here.
